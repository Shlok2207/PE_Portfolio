# PE Portfolio

A clean, responsive personal portfolio website built with plain HTML and CSS. It highlights an AI/ML-focused profile, technical skills, and project work in a simple single-page format.

## Overview

This project is designed as a lightweight portfolio landing page with:

- a hero section
- an about section
- a skills grid
- a project showcase
- a responsive layout for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- No frameworks or JavaScript required

## Project Structure

```text
PE_Portfolio/
├── index.html
├── style.css
├── audit.md
└── README.md
```

## Features

- Professional color scheme and typography
- Responsive layout for multiple screen sizes
- Structured sections for personal branding
- Skills cards for AI/ML-related expertise
- Project cards for showcasing work
- Fast loading static site

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Shlok2207/PE_Portfolio.git
```

2. Open the project folder:

```bash
cd PE_Portfolio
```

3. Open `index.html` in a browser.

You can also serve it locally with a simple static server if preferred:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

To personalize this portfolio:

- update the name and headline in `index.html`
- modify the About section text
- edit the skills and project cards
- adjust colors, spacing, and layout in `style.css`

## Notes

This repository currently contains a static HTML/CSS portfolio, making it easy to customize and deploy on GitHub Pages or any static hosting service.
